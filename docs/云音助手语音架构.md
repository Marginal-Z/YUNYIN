# 云音助手语音架构

本文说明云音助手的实时语音交互：唤醒、识别、对话、朗读、打断，以及音色系统和桌宠。内容包括架构、接口定义、核心代码的位置和测试方案。代码路径都相对于仓库根目录。

## 1. 总体流程

```
麦克风（record，PCM16 / 16 kHz）
   │
   ▼
VoiceWorker（后台 isolate）── VoiceRecognizer
   │   ├─ 唤醒词检测 KWS（sherpa-onnx zipformer，你好云音 / 自定义唤醒词）
   │   ├─ 端点检测 VAD（Silero）：说完 0.7 秒自动结束，6 秒不说话结束
   │   ├─ 离线识别（SenseVoice 高精度 / Paraformer 标准），说话时每 0.7 秒出实时字幕
   │   └─ 打断检测：朗读时持续开口 0.5 秒，或说唤醒词 → VoiceBargeIn / VoiceWake
   ▼
AssistantController.submit(文字, spoken: true)
   │   ├─ 本地指令 parseIntent（播放控制、点歌、音量、定时、音效、控制云音本身）
   │   ├─ 匹配不上的短指令 → CommandFixer 按读音纠错后再试
   │   └─ 其余交给大模型 LlmClient.stream（SSE 流式，函数调用最多 5 轮）
   │          ├─ 文字逐段写进对话气泡（AssistantMessage.text，streaming = true）
   │          └─ 文字逐段交给 SpeechTurn.add → 分句 → 朗读
   ▼
SpeechOutput（音色系统）
   │   ├─ SentenceSplitter 分句；ProsodyPlanner 按语义决定情绪、语速与停顿
   │   ├─ VoiceEngines.chain：首选引擎 → 已配置的云端引擎 → 本地离线 → 系统朗读
   │   │      失败的引擎进入冷却期，自动换下一个
   │   ├─ 串行合成、合成缓存（60 MB，按最近使用淘汰）、边合成边播放
   │   └─ 朗读时压低音乐（onDuck），stop() 立即清空队列（打断）
   ▼
连续对话：朗读结束后自动 listen()，几秒不说话结束本轮
```

桌宠（`lib/pet/`）订阅助手、朗读和播放器的状态，换成对应的表情和动作，见第 6 节。

## 2. 接口定义

### 2.1 语音合成引擎（`lib/voice/tts_types.dart`）

```dart
abstract class TtsEngine {
  String get id;                       // local / system / cosyvoice / fish / elevenlabs
  String get name;
  bool get offline;                    // 是否在本机离线运行
  bool get configured;                 // 云端引擎需要密钥或代理地址
  Set<VoiceLanguage> get languages;    // 目前只有 zh（云音助手只说中文，接口保留语言参数）
  Future<bool> ready(EngineVoice voice, VoiceLanguage lang);
  Future<void> prepare(EngineVoice voice, VoiceLanguage lang, {onProgress, cancel});
  Stream<TtsAudio> synthesize(EngineVoice voice, TtsRequest request, {CancelToken? cancel});
}

class TtsRequest { String text; VoiceLanguage language; Prosody prosody; }
class Prosody    { double rate; Emotion emotion; double intensity; int pauseMs; }
class TtsAudio   { Uint8List bytes; String format /* wav | mp3 | pcm16 */; int sampleRate; }
class EngineVoice { String engine; Map<VoiceLanguage, String> voices; String? model; }
class TtsException { String message; String? engine; bool retryable; }
```

新增引擎只需要两步：实现 `TtsEngine`，然后在 `VoiceEngines` 里注册。引擎不支持的参数由各自的适配代码换算或丢弃，例如：
- ElevenLabs：把情绪换算成 `stability`、`style`，语速限制在 0.7–1.2。
- CosyVoice：语速限制在 0.5–2。
- Fish Audio：只有 s1 模型支持情绪前缀。

### 2.2 音色库（`lib/voice/voice_library.dart`）

`VoiceProfile` 描述一个音色：名称、风格、描述、声音特点、试听文案、支持的语言，以及它在各个引擎里的 `EngineVoice`。

五个预设音色在每个引擎里都对应**不同的声音模型或声音 ID**，不是同一个声音改变音调或语速。用户可以在音色中心覆盖各引擎的声音 ID。

Piper 声音使用完整精度版：int8 量化版只有 13 MB，但有底噪，在 CPU 上合成反而慢 3 倍（实测 RTF 0.16 对 0.05）。

| 音色 | 风格 | 本地离线（ZipVoice 参考录音） | CosyVoice（cosyvoice-v3-flash） | 桌宠 |
| --- | --- | --- | --- | --- |
| 云汐 | 温柔知性 | THCHS-30 A23 | 龙安温 longanwen_v3 | |
| 小柚 | 元气活泼 | THCHS-30 C22 | 龙安欢 longanhuan_v3 | 团团 |
| 晚星 | 轻柔夜语 | THCHS-30 A19 | 龙婉 longwan_v3 | 星月 |
| 清川 | 清朗少年 | THCHS-30 C8 | 龙安洋 longanyang | 阿曜 |
| 暮言 | 沉稳磁性 | THCHS-30 B21 | 龙天 longtian_v3 | |

**本地离线声音**：五个音色共用一个 ZipVoice 模型（sherpa-onnx 导出的 zipvoice-distill-int8-zh-en-emilia，约 104 MB，加 Vocos 24 kHz 声码器约 51 MB，一次下载）。ZipVoice 在约十万小时真实语音（Emilia）上训练，按参考录音的音色说话，声调变化与停顿接近真人。参考录音截取自 THCHS-30（清华大学，Apache 2.0），每段约 4 秒，放在 `assets/voices/`，许可说明见 `assets/voices/NOTICE.txt`，并显示在“开源许可”中。

- 之前用的小模型（Piper huayan / xiao_ya / chaowen、Matcha baker、ZhiHuiLaoZhe）只有词典里的词才有正确变调，“很好”“我给你”这类短语逐字按原调念；Kokoro v1.1 中文同样如此。装好 ZipVoice 后删除这些旧模型。
- 速度（Ryzen 9 8945HX，4 线程，约 4 秒参考录音）：4 步 RTF 0.23–0.31。参考录音越长越慢（10 秒的录音约慢一倍），所以截取 4 秒左右。
- 采样步数按设备速度自动调整（`zipVoiceSteps`）：RTF 超过 0.7 时减一步，低于 0.35 时加一步，2–4 步之间。日志里每句都会写 `tts local: 音色 步数 耗时 RTF`，可在“问题诊断”里看到。
- 评测：用 SenseVoice 回识两句测试文本，五个音色的准确率 98.6–100%。

**CosyVoice**：声音 ID 必须与模型对应（v3 的 ID 不能用于 cosyvoice-v2），音色列表见阿里云文档“CosyVoice 系统音色列表”。

### 2.3 朗读（`lib/voice/speech_output.dart`）

```dart
class SpeechOutput extends ChangeNotifier {
  Future<void> say(String text, {VoiceProfile? voice, Emotion? emotion});
  SpeechTurn begin({VoiceProfile? voice});   // 流式：大模型边生成边 add
  Future<void> stop();                        // 打断：清空队列、停止合成与播放
  bool get speaking;
  String? lastEngine, lastError;
}

class SpeechTurn {
  void add(String delta, {Emotion? emotion});  // 开头的 [开心] 等情绪标记会被取出
  Future<void> end();                          // 等说完；被打断时立即返回
}
```

### 2.4 大模型（`lib/assistant/llm_client.dart`）

支持任何兼容 OpenAI `/chat/completions` 的服务，接口地址、模型和密钥都由用户自己填写。
- `complete(messages, tools)`：一次性返回结果。
- `stream(messages, tools, onText)`：SSE 流式返回。会按 `index` 把 `tool_calls` 的增量片段拼成完整的函数调用。服务不支持流式、直接返回整段 JSON 时也能自动兼容。

系统提示词要求回答简短、口语化，并在开头加上情绪标记（`[开心] [兴奋] [温柔] [平静] [难过] [认真]`）。标记用来调整朗读语气，不会显示，也不会读出来。

### 2.5 助手可以调用的功能

- **本地指令**（`lib/assistant/intents.dart`，不需要大模型）：播放控制、点歌 / 歌手、音量、播放模式、收藏、定时关闭、正在播放什么、打开歌词、均衡器与音效。
- **控制云音本身**（`AppIntent`）：平台模式、深浅色、主题色、播放页样式，桌面歌词、状态栏歌词、歌词翻译和液态玻璃的开关，桌宠、音色，下载这首歌，播放每日推荐 / 我喜欢的音乐 / 最近播放，打开页面与搜索。
- **大模型函数**：`play_songs`、`play_artist`、`add_to_queue`、`control_playback`、`set_volume`、`set_sleep_timer`、`set_sound`、`like_current_song`、`control_app`（使用与 `AppIntent` 相同的动作）、`get_now_playing`、`get_lyrics`、`get_queue`、`get_listening_stats`。

## 3. 实时对话的状态

| 状态 | 进入条件 | 离开条件 |
| --- | --- | --- |
| 待机（唤醒检测） | 打开语音唤醒 | 检测到唤醒词，或点按麦克风 / 桌宠 |
| 听 | 唤醒、点按、打断，或者连续对话中一轮回答结束 | 说完（静音 0.7 秒）、6 秒没有说话，或最长 15 秒 |
| 思考 | 识别出文字 | 大模型输出第一个字，或者本地指令执行完 |
| 说 | 第一句合成完成 | 说完；或者用户开口、说唤醒词、点按，打断后转入“听” |

## 4. 设置与持久化

- **`AssistantSettings`**：语音唤醒、识别模型、唤醒词、朗读回答、连续对话、开口打断、大模型配置、桌宠与桌宠大小。
- **`VoiceSettings`**：默认音色、首选引擎、按语义调整语气、语速、各引擎的密钥 / 代理 / 模型，以及用户覆盖的声音 ID。

两者都保存在 SharedPreferences 里。密钥只保存在本机，只发送给对应的服务。**客户端代码里不写死任何密钥。**

## 5. 下载与校验

- **识别、唤醒、端点检测、离线声音的模型**：从 sherpa-onnx 官方发布页下载，网络不畅时依次改用 ghfast.top、hf-mirror（只用于识别模型）。下载后核对写死在代码里的 SHA-256，校验和解压在后台 isolate 里进行（`compute`）。离线声音的压缩包边解压边写入磁盘（`extractFileToDisk`），不整个读进内存。
- **CI 构建时下载的 Gradle、libmpv 等 GitHub 发布文件**：由 `tool/ci/gh_release_download.sh` 下载。官方地址失败时改用 GitHub API，下载后核对官方的 SHA-256 / MD5。

## 6. 桌宠

- **`pet_rig.dart`**：三张角色原图，以及五官的位置与颜色。
- **`pet_painter.dart`**：在原图上实时画出眨眼、笑眼、闭眼、各种嘴型、腮红，以及音符、爱心、Zzz、思考泡泡和声波圈。
- **`pet_host.dart`**：`PetMoodRules` 按状态决定表情，优先级为：倾听 > 思考 > 说话 > 出错 > 刚完成 > 随音乐摇摆 > 打瞌睡 > 待机。
- **Android**：`PetOverlay.kt` 在单独的轻量 Flutter 引擎（不注册插件）里，用透明的 `FlutterTextureView` 画桌宠。点按、长按、拖动由原生代码处理；长按时先振动，松手后才打开云音。
- **桌面端**：desktop_multi_window 创建置顶的透明小窗口。
