逐字歌词

当前行随演唱逐字点亮，弹簧曲线平滑滚动；Android 上全屏沉浸显示，控件闲置后自动隐藏。

封面取色

播放页背景从专辑封面中提取主色与光晕，切歌时颜色缓缓过渡，文字始终保持清晰。

本地音乐

导入 MP3、FLAC、M4A、OGG、WAV，自动读取歌名、歌手、封面与内嵌歌词，与在线歌曲混合播放。

五种主题色

浅色、深色或跟随系统；应用图标也会跟随你选择的主题色一起变化。

应用内更新

自动检查新版本，下载与你的平台、架构和安装方式匹配的安装包，高版本直接覆盖安装。

一套代码，四个平台

Flutter 构建，支持设备最高刷新率；播放源是可插拔接口，未来可以接入更多平台。

下载

所有安装包都来自 GitHub Releases，由 CI 自动构建。

Android

Android 7.0 及以上
  • arm64-v8a大多数手机
  • armeabi-v7a较旧的 32 位设备
  • x86_64模拟器、部分平板
  • 通用安装包不确定时选择

Windows

Windows 10 / 11 · x64
  • 安装程序推荐，支持应用内更新
  • 便携版 zip解压即用

Linux

x64 / arm64
  • deb · x64Debian、Ubuntu
  • AppImage · x64任意发行版
  • tar.gz · x64便携版
  • deb · arm64
  • AppImage · arm64
  • tar.gz · arm64

macOS

Intel 与 Apple 芯片通用
  • macOS 应用 zip首次打开请右键选择“打开”
